# Explainable-AI-for-Cardiovascular-Risk-Assessment
Explainable AI-based cardiovascular disease risk assessment using machine learning. Compares Logistic Regression, Random Forest, XGBoost, ANN and DNN, with XGBoost selected as the final model. Includes SHAP explainability, risk stratification, calibration, fairness analysis, counterfactual what-if analysis, and a Flask prototype.
